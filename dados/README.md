# dados/

Local para **descrições** dos exports usados nas análises (Shopee Ads, Mercado Livre, Bling). Os arquivos de dados em si (`.csv`, `.xlsx`, `.xml`, `raw/`, `exports/`) ficam **fora do git** (ver `.gitignore`).

Ao usar um export, registre aqui (ou em `historico/decisoes.md`): origem, período, data de extração, colunas relevantes e limitações (ex.: dias sem veiculação por ruptura de estoque). Nunca versionar dados pessoais de clientes, XMLs integrais, e-CNPJ ou credenciais.
