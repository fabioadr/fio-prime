## 3.5. Ficha de atributos — sapatilha feminina super invisível Hoahi 33–38

**Origem:** descrição de produto enviada em 11/08/2026, apresentada ao atender uma dúvida de cliente.

| Atributo | Informação descrita |
| --- | --- |
| Produto | Kit de **3 pares** de meias sapatilha super invisível feminina |
| Tamanho | **33 ao 38** |
| Composição | **75% algodão**, **22% poliéster**, **2% elastano**, **1% elastodieno** |
| Fixação | **Silicone no calcanhar**, para ajudar a manter a meia no lugar |
| Uso informado | Sapatilhas, tênis e calçados baixos |
| Proposta de valor | Discrição, ajuste confortável, conforto no uso diário |
| Cores descritas | Preto, branco, bege, kit sortido |
| Condições citadas no anúncio | Produto original; nota fiscal; envio imediato; garantia contra defeitos de fabricação |

**Atenção editorial:** a dúvida de uma cliente era se a meia aparece no **scarpin**. Não garantir invisibilidade em todo scarpin: o recorte de cada sapato pode expor a borda da meia. Afirmar com segurança apenas o que a descrição do produto comprova; para modelo específico, pedir foto/recorte se necessário.

A existência de **bege** na descrição acima não significa que bege era uma das variações campeãs listadas no retrato de 09/08; são contextos diferentes.
